# Golden's Systems Lab

Golden's Systems Lab (GSL) is a software development organization focused on game systems, tooling, and framework development.

The organization currently hosts projects related to animation technology, player controllers, input handling, gameplay systems, development utilities, and supporting infrastructure. While GEngine is the primary project today, GSL is intended to serve as a home for future frameworks, tools, and experimental systems.

## Current Areas

* Animation systems and tooling
* Character controller frameworks
* Input management systems
* Development and debugging tools

## Community

GSL is an active development workspace where projects are designed, tested, and iterated in public. Feedback, discussion, bug reports, and contributions are welcome.
